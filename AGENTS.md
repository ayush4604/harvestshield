# HarvestShield project instructions

Read `docs/CONTEXT.md`, `docs/MILESTONES.md`, and `docs/PLAN.md` before continuing work.
Update context and milestones after material changes and record verification evidence.

User requirements: build here on Desktop; FastAPI backend; Streamlit frontend;
classical machine learning only; no CNNs or hardware. Preserve these choices.

Never present synthetic observations, evaluation scores, forecasts, or savings as
real market evidence. Keep demo and imported market data separate. Forecasts use
seven calendar days; compare equivalent crop/variety/grade and units. Do not
randomly split temporal observations. Never commit API keys or log request URLs
containing them. Real historical-data coverage must be audited before claiming
field readiness. Do not deploy externally without a user request.
